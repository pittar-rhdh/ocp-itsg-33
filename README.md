# OpenShift 4.22 Reference Architecture for ITSG-33

[Open in Dev Spaces](https://devspaces.apps.prime.pitt.ca/#https://github.com/pittar-rhdh/ocp-itsg-33)

A reference architecture that maps Canadian **ITSG-33** security controls (PBMM / CCCS Medium
profile) to **Red Hat OpenShift Container Platform 4.22** capabilities. It includes configuration
examples and evidence collection guidance.

Start at **[docs/index.md](docs/index.md)**.

The documentation is published with Backstage TechDocs (`mkdocs.yaml`, `techdocs-core`).
